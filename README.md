# FootballPulse ⚽

A responsive live-football dashboard for the **Premier League, LaLiga, Bundesliga, Serie A and Ligue 1**.

## Features
- Live match scores and status
- Automatic refresh every 30 seconds
- League switcher
- Current standings
- MatchMind assistant that answers questions from the loaded data
- Responsive dark UI for desktop and mobile

## Data
Match and standings data are loaded client-side from ESPN's public sports API endpoints. Because this is a static site, no private API key is embedded.

## Run
Open `index.html` in a browser or deploy the repository with any static hosting provider.
